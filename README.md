## Expense Control
Expense Control is a web application that allows you to set a budget, add expenses, view the amount of budget spent, available funds, and filter your expenses for better control over your finances.
The project was built using Vue 3.

## Installation
1. Clone the repository:
    ```
    git clone https://github.com/karemun/ExpenseControl.git
    ```
2. Enter the project directory:
    ```
    cd expensecontrol
    ```
3. Install the project dependencies:
    ```
    npm install
    ```
4. Run the application with the following command:
    ```
    npm run dev
    ```
5. Access the app by entering the route: `http://localhost:5173`
